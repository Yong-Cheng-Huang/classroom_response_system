# 本機操作交付

2026-11-26。功能、已知缺口與整合驗收狀態以 [整合報告](integration-acceptance.md) 為準；本文件存在不代表全部效能與 42 分頁流程已通過。

## 啟動與資料

使用 Node.js 24.22.3／npm 11.19.1，在專案目錄執行 `nvm use`、`npm ci`。新環境才從 `.env.example` 複製 `.env`，填入自己的非空 `TEACHER_PASSWORD`；既有環境不要覆蓋原設定或刪除 data。

```sh
npm run db:migrate
npm run dev
```

前後端共用 [http://127.0.0.1:3000](http://127.0.0.1:3000)，只綁本機。正式建置使用 `npm run build` 後 `npm start`。停機使用 Ctrl+C，重啟沿用同一 APP_DATA_DIR 與來源；不要同時啟動第二個同埠程序或以換埠解決身分恢復問題。密碼未設定時老師登入停用。沒有預設密碼、網頁改密碼或忘記密碼功能；改啟動密碼並重啟會撤銷舊老師，學生及活動依原規則保留。

## 老師與學生完整流程

1. 在老師分頁登入；另一個老師分頁另行登入，共用同一活動但分頁登出獨立。
2. 新環境依 [Google 設定說明](google-oauth-setup.md) 配置 OAuth client，從老師端另開授權頁自行同意。不要把密碼、client secret、token 貼入對話。Google 連結由所有老師共用，老師登出不解除。
3. 貼 Guided Notes 網址，選 2～20 組；有 gid 使用指定表，無 gid 多表先選表。確認完整解析後匯入。待開始／已結束替換須確認；讀取、取消或匯入失敗保持原場。
4. 每位學生另開同一 Chrome 的分頁，設定暱稱並選組；每頁身分獨立，同名合法。待開始可離組、改名、換組，開始後不能首次加入或離組。
5. 老師開始後開放全部題目。各組自由選題，題組須全部子題一併填寫；每答案修剪後 1～200 個可見字元，可換行／emoji。每組每題一次，以伺服器有效接收順序排名，不比正確性。
6. 草稿只保留在當前分頁；同組別人先提交會同步鎖定。請求回覆遺失可用原請求再次確認，避免用不同請求覆寫。學生結束前沒有他組答案或排名。
7. 老師確認結束後不可重開；老師看全部答案，學生看成功組答案、本組三種結果及成功題數，題組只算一題。無人題不使用來源舊答案作為本場成功答案。
8. 新活動只有完整匯入成功才清除舊結果、撤銷舊學生並清草稿；學生保留暱稱但須重新選組。沒有歷史活動封存及查詢。

## 重新整理、斷線與暫停

原分頁重新整理保留有效身分、暱稱及自己的草稿；原生複製分頁必須自行登入／選組，不接手原頁。不要複製 sessionStorage 或 window.name 來搬移身分。關閉或斷線後約 30 秒移除，重整不重複計人；HTTP 查詢不延長寬限。

固定期限是登入／加入起算 12 小時，重連、重整、停機不延長。停機後依原有效狀態恢復，已撤銷、已到固定期限及舊活動不復活。不明中斷依 D38 的最後已提交 CONNECTED／GRACE 政策重新提供恢復寬限；這不是精確判定歷史停機時刻。

D39 已確認：真正 Chrome 凍結／丟棄或 macOS 休眠另列暫停，一般背景仍適用原正常同步門檻。解除暫停依原身分期限、撤銷、活動與分頁證明裁定，不保證暫停後仍有效。受控 Chrome 凍結及固定到期已實測；沒有對使用者電腦自動執行 OS 休眠或宣稱已驗證真正丟棄。

## Sheets 匯出與未知結果

老師僅能於已結束時匯出至原試算表／工作表。依 [匯出說明](guided-notes-export.md) 選三模式；**D31 必須由老師及協作者從預檢至完成暫停編輯**，系統無法強制鎖表。所有題目及目標先核對，有衝突整次停止，不自行找其他欄位。

待確認不代表未寫入。可重新授權及「再次核對」，不能盲重送；沒有權限或文件刪除仍可再次確認放棄核對後匯入其他文件。放棄不等於回滾，成功換場才刪舊場完整資料並保留最少未核實標記；取消／新匯入失敗保持舊場。U03 未核實範圍仍隔離，沒有強制覆寫或自動解除功能。

## 備份、回復與檢查

```sh
npm run db:backup -- backups/classroom.db
npm run db:restore -- backups/classroom.db data/restored/classroom.db
npm run typecheck
npm test
npm run test:browser
npm run test:startup
```

備份目標必須不存在；回復到新目錄，先停止服務再變更 APP_DATA_DIR，不能在運行中覆換資料庫。純 SQLite 備份不含 Google 金鑰及加密憑證，缺少相符憑證時需重新授權，不清活動；本機備份也不能回滾已寫入 Sheets。詳細限制見 [資料庫文件](database.md)。

`probe:acceptance42` 會讀既有授權、建立私有 Sheets 測試副本並實際寫入，只用隔離 SQLite；不是唯讀檢查。`probe:performance` 執行 F1～F3 各 20 輪固定程序（至少半小時，失敗時保存紀錄後停止）；`probe:performance-preflight` 是 F3 單輪測量工具預檢，不是固定 20 輪正式程序。兩者使用自己的 Chrome 測試設定檔，不刪正式活動、不關閉使用者既有分頁。正式驗收的未通過項與測試版本須隨交付保留。

原1秒同步／計時與5秒恢復保留為改善目標；使用者已確認D41採紀錄型驗收，13.3依既有功能、量測與缺失清單完成。已加入身分續接完成後才開正確角色通道、避免重疊輪詢、HTTP 單獨失敗恢復及有效活動通道的 500ms 計時脈衝。脈衝沿用既有校時錨點，身分到期／撤銷仍停止。

## 下載所有組別的 CSV

活動結束後，老師可在「匯入 Guided Notes」下方的「匯出 CSV」按「下載送出紀錄 CSV」。不需 Google 連結，Sheets 匯出待確認也可下載。內容包含所有組別已受理提交，含未搶到的答案；姓名為送出者暱稱，題組每個子題一列，第一名成功欄為「是」。零提交只下載表頭。

檔案使用 UTF-8 BOM，供 Excel 開啟；多行中文、emoji、逗號與雙引號均保留在原欄位。公式型外部文字會加文字安全前綴；純數字文字與前導零仍可能受 Excel 型別判斷影響。細節見 [CSV 匯出說明](submission-csv-export.md)。請在建立新活動前下載，成功換場後不能下載舊場紀錄。

D41驗收只影響本階段完成判準，不延長身分期限或放寬資料權限。原始效能數據與未完成60輪維持可查，詳見 [紀錄型驗收政策](evidence/performance-acceptance-policy.json)。
