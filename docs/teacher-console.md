# 老師端管理實作與驗證

日期：2026-11-26（Asia/Taipei）。Change：`build-local-classroom-response-system`。本次完成第 10 群組 10.1～10.4，累計 63／85，尚餘 22 項；第 11～13 群組保持未完成。

## 老師操作

使用 Node.js 24.22.3 執行 `npm run dev`，在 http://127.0.0.1:3000 選「老師登入」，輸入本機設定的老師密碼。可另開老師分頁，以相同密碼登入同一場活動；登出只撤銷目前分頁，不解除共用 Google 連結。沒有設定密碼時不能登入，沒有預設密碼；空密碼同樣由伺服器回覆繁體中文錯誤。

首次使用 Google 文件時按「連結 Google」，另開授權頁完成授權後返回原老師分頁。全部有效老師共用一個 Google 連結；解除本機連結後不再允許匯入，但不刪除活動結果。設定步驟見 `docs/google-oauth-setup.md`，正式 Google 整合證據沿用第 6 群組，本階段回歸使用隔離替身，沒有重新要求真實授權或修改外部試算表。

匯入時貼上 Sheets 網址、設定 2～20 的整數組數。網址未指定 gid 且有多張表時，先選工作表；所有內容解析完成後才能匯入。有目前活動時，按「確認替換並匯入」前會明示：清除舊題目、組員、全部作答結果，尚未匯出的結果將無法再匯出，且只有新活動完整建立成功才清除。取消或失敗保留舊場。搶答進行中禁止匯入；其他老師於讀取後開始活動，本頁也不能提交替換，伺服器仍會重新驗證版本及階段。

組數缺值、非整數或超出範圍，以及未填網址，均以繁體中文說明。登入及匯入表單停用瀏覽器原生驗證氣泡，避免由瀏覽器語系顯示英文錯誤；網址格式、Google 權限及解析仍由既有伺服器契約驗證。操作中的重複匯入由同步防重入旗標阻止。

## 題目預覽

在「題目預覽」點題號，顯示該題全部敘述及所有子題。再次點同一題關閉，點另一題只留下新題。預覽為此分頁的 React 狀態，不寫入伺服器或跨分頁儲存，不改變其他老師預覽、學生顯示或活動階段。重整可回到未選預覽；不把範例兩個子題當上限。

## 開始、結束與計時

待開始時按「開始搶答」開放全部題目。進行中按「結束活動」會再次確認；取消不送出結束操作。有效確認後結束且不可重開，需重新匯入新場次。另一老師已結束活動或活動版本改變時，本頁過期的結束確認框自動關閉，不再允許按舊確認。

計時沿用伺服器開始／結束時間與既有校時機制，停機仍算入活動時長；結束總時長不繼續累加。重複開始、重複結束與過期版本由後端拒絕，不重設原時間。多老師與重整皆使用相同時間依據。

## 完整提交監看與結果

「即時作答狀況」逐題列出已提交組數及每個尚未提交組別。每筆有效提交依伺服器提供的 rank 排列，顯示名次、組別、送出者及原提交時間；展開「查看完整答案」可查看單題或全部子題。只有 rank 1 標示「搶答成功」，後續名次標示「已送出，未搶到」。成功不代表正確，系統不比對來源答案或提供批改。

提交時間直接呈現伺服器的 `YYYY-MM-DD HH:mm:ss.SSS（Asia/Taipei）`，不依作業系統／瀏覽器時區重算，不以時間文字排序。同一毫秒仍有不同且唯一名次。來源答案不充當本場提交；未提交組別不產生虛構答案、送出者、時間或名次。

活動結束後標題改為「本場完整結果」，全部組別答案及排名繼續保留，包括沒有搶到第一名的答案。完全沒有提交的題目顯示「無人搶答」，重整或服務重啟後維持，直到完整成功建立新活動。資料以既有老師專屬投影取得，沒有把老師完整資料傳給學生後再隱藏。這不代表學生完整結果畫面已完成，該內容仍由 11.3 承接。

## 驗證證據與限制

- 新增兩項真 Chrome 流程：多老師獨立預覽與完整監看，以及登入／Google／匯入階段操作。
- 同毫秒案例使用固定伺服器時鐘及正式 HTTP 命令入口；學生透過真正 React 表單提交，名次及答案由 SQLite 保存，兩筆時間相同而名次為 1、2。不是直接在測試中偽造排名畫面。
- Google OAuth／Sheets 讀取在新介面測試中使用隔離替身；真實授權及匯入沿用既有第 6 群組證據，不冒稱本次新增真 Google 寫入驗收。
- 其餘單元、整合、Chrome 與啟動最終結果見 `docs/evidence/teacher-verification.json`。隔離測試不寫入正式活動或外部 Sheets。
- 截圖：`test-results/teacher-monitor-desktop.png`、`teacher-monitor-mobile.png`。人工檢查預覽、名次、時區、完整子題答案、純文字 HTML 外觀與窄螢幕換行，390px 沒有水平溢出。
- 原始需求及 proposal／design／10 份 spec 保持原樣；套件版本與 schema 3／18 張表不變。U02 凍結／休眠、U03 未核實範圍政策及 42 分頁／20 輪完整效能仍保留，這些小規模流程不代替第 13 群組驗收。
