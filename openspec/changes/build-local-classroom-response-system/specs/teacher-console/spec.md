# Spec Delta

## Purpose

定義老師於本機課堂活動中可觀察及操作的管理介面，確保預覽只影響自身分頁，活動控制受伺服器驗證，並能即時掌握全部組別的提交順序、答案與最終結果。

## ADDED Requirements

### Requirement: TC01 單題預覽切換
系統 SHALL 讓老師點擊題號預覽題目敘述，題組列出全部子題；再次點相同題號關閉，切換另一題則關閉前題，同時最多一題，預覽僅影響目前分頁。

#### Scenario: 預覽題組與關閉
- **GIVEN** 老師已登入且有單題及題組
- **WHEN** 點擊題組題號、再次點擊、再依序點擊兩個不同題號
- **THEN** 先顯示全部子題，再關閉，最後僅顯示後一題，其他分頁預覽不變

### Requirement: TC02 老師管理操作
系統 SHALL 提供登入、登出、Sheets 網址匯入、2～20 組設定、Google 連結管理、開始、結束與三模式匯出入口，依活動階段及權限啟用；提供匯出結果狀態、重新核對及 GE14 的放棄確認，不能只靠按鈕禁用防止越權，活動確認依 AL02、AL03。

#### Scenario: 操作入口與直接呼叫一致
- **GIVEN** 老師查看進行中的活動
- **WHEN** 查看控制區或直接嘗試匯入與匯出
- **THEN** 匯入及匯出均不可執行，結束需確認；未登入分頁無法執行所有老師操作

#### Scenario: 老師確認放棄不明匯出
- **GIVEN** 匯出結果待確認且老師準備建立新活動
- **WHEN** 顯示放棄核對確認
- **THEN** 清楚說明原表可能已修改、不會自動回滾、舊結果會於成功換場後清除及未核實範圍受保護；取消則不執行替換

### Requirement: TC03 即時完整提交監看
系統 SHALL 讓老師即時查看每題各組提交狀況、各筆答案、名次、組別、提交者暱稱與提交時間，第一名標示「搶答成功」，未提交組別不得產生虛構答案或名次。

#### Scenario: 各組先後作答
- **GIVEN** 活動進行中且兩組依序有效提交同題
- **WHEN** 伺服器完成提交
- **THEN** 老師看到兩組提交狀況、完整答案、依接收順序的名次與送出者，僅第一組標示搶答成功

### Requirement: TC04 結束後完整結果
系統 SHALL 在活動結束後保留並提供老師查閱全部組別答案、名次與提交時間，無任何有效提交的題目顯示「無人搶答」，直到成功建立新活動才清除。

#### Scenario: 查閱未搶到及無人題目
- **GIVEN** 已結束活動含未搶到的提交及無人作答題目
- **WHEN** 老師查看結果或重新整理
- **THEN** 仍可查看所有提交，包括未搶到的答案，無人題目明確標示且不補造成功組

### Requirement: TC05 正確計時與臺灣提交時間
系統 SHALL 顯示依伺服器時間推算的搶答計時與結束總時長，提交時間以 Asia/Taipei、YYYY-MM-DD HH:mm:ss.SSS 顯示並標示時區；相同顯示時間不得導致並列名次。

#### Scenario: 同毫秒提交
- **GIVEN** 兩組的提交顯示為相同毫秒
- **WHEN** 老師查閱結果
- **THEN** 仍依伺服器順序顯示不同名次，提交時間標示臺灣時區；重開老師分頁顯示正確活動時長
