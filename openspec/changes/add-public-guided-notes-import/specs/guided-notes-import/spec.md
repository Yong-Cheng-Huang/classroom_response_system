# Spec Delta

## MODIFIED Requirements

### Requirement: GI01 網址與組數輸入
系統 SHALL 接受老師提供的原始Google Sheets網址及2～20整數組數，提供公開學習單免Google登入與Google帳號授權兩種匯入模式；仍須有效本機老師身分。未指定模式的既有請求維持OAuth行為。格式無效、無讀取權限、網路失敗或組數超界時提供繁體中文說明，不得建立部分活動。

#### Scenario: 組數邊界
- **GIVEN** 老師提供有效範本網址
- **WHEN** 組數為 2 或 20
- **THEN** 可進行匯入；1、21、非整數及缺值均拒絕且原活動不變

#### Scenario: 文件不可讀
- **GIVEN** 原活動已有資料
- **WHEN** 網址無效、文件不存在、缺少權限或讀取失敗
- **THEN** 顯示可理解的繁體中文原因且所有原資料與身分保持不變

#### Scenario: 公開模式免 Google 登入
- **GIVEN** 有效本機老師尚未連結Google，系統已設定公開讀取金鑰，學習單原表已公開分享
- **WHEN** 選擇公開模式、貼原始Sheets網址並填入合法組數
- **THEN** 可完整解析及確認匯入，不要求Google登入或OAuth測試人員資格

#### Scenario: 保留原授權匯入
- **GIVEN** 老師使用既有OAuth連結存取有權讀取的私有文件
- **WHEN** 選擇Google帳號授權模式，或舊客戶端請求沒有指定模式
- **THEN** 使用原帳號授權流程，gid、選表、2～20組、驗證、確認與原子換場規則保持


## ADDED Requirements

### Requirement: GI08 公開原表完整讀取
系統 SHALL 在公開模式只讀取公開分享的原始試算表，保留既有解析所需的工作表、題目、合併範圍、答案定位、必要格式及原內容；沿用GI02～GI07，不因免Google登入降低題組解析、原子替換或學生資料保護。公開可查看即可，不要求公開可編輯，也不將讀取成功視為可寫證明。

#### Scenario: 公開唯讀學習單
- **GIVEN** 單題或混合題組範本設為知道連結的任何人可查看
- **WHEN** 公開模式依gid或多表選擇讀取並確認匯入
- **THEN** 題數、子題、位置、原內容及必要格式與原解析契約一致，原Sheet不被修改，來源答案不傳學生

#### Scenario: 私有文件或公開讀取未就緒
- **GIVEN** 系統缺公開讀取金鑰、金鑰無效／受限、文件未公開、文件不存在或外部服務失敗
- **WHEN** 公開模式要求讀取
- **THEN** 提供對應的安全繁體中文說明，不啟動OAuth、不替換活動，不清除原組員、身分或作答；原OAuth模式仍可依其權限使用

#### Scenario: 發布網址與原表網址區分
- **GIVEN** 老師貼的是發布網頁、CSV輸出網址或其他非原始Sheets網址，或僅發布到網路但原表未公開分享
- **WHEN** 嘗試公開匯入
- **THEN** 不爬取或反查原表，不把發布設定當作API可讀證明；提示使用原始Sheets網址及公開可讀分享設定，舊活動不變

### Requirement: GI09 匯入模式固定及獨立裁定
系統 SHALL 由匯入意圖固定公開或OAuth模式，檢查原老師、期限、活動及確認版本；不得在選表或提交時變更模式、混用別人的意圖或靜默切換憑證。公開模式不依賴OAuth連結版本；OAuth模式仍受既有連結撤銷與版本檢查約束。

#### Scenario: 公開讀取期間解除 Google 連結
- **GIVEN** 有效老師的公開匯入尚在讀取，活動及意圖期限均有效
- **WHEN** 另一老師解除或切換共用Google連結
- **THEN** 不僅因OAuth變動而取消公開候選；本機老師登出、到期、活動開始或版本改變仍依原規則拒絕提交

#### Scenario: OAuth讀取期間解除連結
- **GIVEN** 有效老師正透過OAuth讀取候選
- **WHEN** 共用Google連結解除或版本改變
- **THEN** 依原行為拒絕該候選，原活動保持不變，不自動轉為公開模式

#### Scenario: 不暗中更換讀取身分
- **GIVEN** 老師有OAuth連結，但公開模式對某文件讀取失敗
- **WHEN** 重試、選表、提交或嘗試在舊意圖中改模式
- **THEN** 不能用OAuth掩蓋公開讀取失敗；必須另行明確選OAuth並開始新意圖，其他老師不能接用原意圖
